# 🚀 Ascendita: Helping You Rise in Your Career

## Overview
Ascendita leverages a Supervisor Multi-Agent Architecture to provide a seamless, intelligent job-hunting experience by tailoring searches, generating cover letters, and analyzing resumes.


## Key Features
- **Personalized Job Search**: AI-driven system finds job listings tailored to the user’s industry, experience, and location.
- **Custom Cover Letters**: Generates unique, job-specific cover letters based on resume details and job descriptions.
- **Company Research**: Collects and summarizes key employer insights from online sources.
- **Resume Analysis**: Extracts relevant details from uploaded resumes to improve job-matching accuracy.
- **Interactive UI**: User-friendly experience with a sleek, easy-to-navigate Streamlit interface.
- **Multi-Agent System**: Implements specialized agents, including Supervisor for workflow management, JobSearcher for retrieving job listings, ResumeAnalyzer for resume processing, CoverLetterGenerator for crafting personalized cover letters, WebResearcher for gathering employer insights, and ChatBot for handling general queries and conversational support.

## Tech Stack
- **LangGraph**: Manages and orchestrates multi-agent workflows.
- **Streamlit**: Provides an interactive and user-friendly interface.
- **OpenAI API**: Powers natural language processing for resume analysis and cover letter generation.
- **SerperClient**: Enables job search and employer research via web scraping.
- **FireCrawlClient**: Retrieves detailed company information through advanced web search.
